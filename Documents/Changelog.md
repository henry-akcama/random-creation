## Pre-adoption history — the app before AI PM

Backfilled at the v3.3 close-out at milestone granularity, per AI_Project_Manager.md §12. These are APP versions, predating both git and the method, so there are no commits behind them. They locate the record rather than being it: the app's own user-facing changelog at Source\RandomCreation\RandomCreation\changelog.txt, the frozen design records in Documents\Design\, and the pre-git source snapshots in Documents\Archive\.

### App v3.0 — June 2026, built 2026-06-06

The Groups release, and much the largest of the three. A CategoryGroup layer was inserted between Collections and Categories, making the hierarchy Collection → Group → Category → Option, with existing data migrated automatically on first launch. Manage Content was rebuilt around groups with a new group detail panel; weight tiers expanded to six; inline editing, undo (Ctrl+Z), an internal copy/cut/paste clipboard, Duplicate (Ctrl+D) and Ctrl+drag copy arrived; results became grouped cards; and Mark as Drawn, the AI Prompt feature, print preview, rebuilt presets, Collections Management, data export, a keyboard shortcuts reference and toast notifications all landed. The model classes lost their Random prefix. Detail: changelog.txt "Version 3.0" section, 22 headings; RandomCreation_ProjectContext_v3_0.md remains authoritative for the design. The build date comes from the release exe's timestamp — no dated source states it. This is the version still running on the one live installation, and the version whose shipped build loads v2.0 theme dictionaries: the defect recorded as BUG 1 and fixed in v4.0.

### App v2.0 — May 2026

Renamed from Creature Crafter to Random Creation. Collections were introduced above categories, giving the app more than one independent content set for the first time. Manage Content became its own screen; presets, themes, per-option enable/disable with probability weighting, result card dimming, rebuilt drag and drop, history improvements, a settings screen, a resizable sidebar, a summary bar and the custom borderless window all landed. The save file moved out of a single JSON beside the exe and into the data\ folder that survives to this day. Detail: changelog.txt "Version 2.0" section, 13 headings; RandomCreation_ProjectContext_v2.0.md. Source: Documents\Archive\v2.0\, the only surviving copy.

### App v1.0 — date not established

Shipped as Creature Crafter, the original working title. A single flat list of categories, each holding options; Generate picked one option per enabled category and displayed the combination. C# / WPF on .NET 8, System.Text.Json, no NuGet packages — the constraints the project still runs under today. Data lived in creature_crafter_data.json beside the executable, saved on every change and deliberately excluded from the single-file publish so users could back it up or transfer it. Already documented at the time as a general-purpose combination generator rather than a creature-specific one, a position CLAUDE.md still enforces. NO DATE IS RECORDED and none is inferred: changelog.txt has no v1.0 section, the context doc is undated, and the archived source files all carry 2026-07-30 extraction timestamps rather than original ones. Only that it precedes v2.0's May 2026 is established. Detail: RandomCreation_ProjectContext_v1.0.md; source in Documents\Archive\v1.0\.
