================================================================================
Random Creation — Changelog
================================================================================


Version 4.0 — in development
================================================================================

Fixes
--------------------------------------------------------------------------------
The app now uses the correct v3.0 theme files. Version 3.0 accidentally shipped
with the older v2.0 theme colours, which left the group card headers on the
Manage Content screen without their background tint in both themes.

A maximised window no longer extends underneath the taskbar. Maximising,
Win+Up and drag-to-top now stop at the taskbar edge on whichever monitor the
window is on, wherever the taskbar is docked. The window's rounded corners
and outline also square off while maximised, matching standard windows.


Version 3.0 — June 2026
================================================================================

Groups — new data layer
--------------------------------------------------------------------------------
A new CategoryGroup layer sits between Collections and Categories. Every category
now belongs to a named group within its collection. Groups can be enabled or
disabled independently. Results are displayed grouped by their group name — one
card per group on the main screen and in history. The data hierarchy is now:
Collection → Group → Category → Option.

All existing data is automatically migrated on first launch. Each collection's
flat category list is wrapped into a single group named after the collection.
History and presets are cleared on migration (a backup prompt is offered).

Manage Content — complete rebuild
--------------------------------------------------------------------------------
The sidebar is rebuilt around groups. Groups appear as expandable cards with a
chevron and category count. Click a group to expand or collapse it and open the
group detail panel on the right. Ctrl+click to multi-select groups for bulk
operations.

Categories appear as rounded card rows inside their group. Click to select and
show options. Second click on any name opens inline rename — no more dialogs for
renaming. Inline rename works for options, categories, groups, presets and
collections everywhere in the app.

A search bar filters groups and categories simultaneously. Non-matching groups
collapse. Non-matching categories dim. Clearing search restores prior expand state.
Placeholder text shows when the search bar is empty.

Add Category footer shows a + icon at the bottom of each expanded group card.

Group detail panel
--------------------------------------------------------------------------------
Selecting a group opens a compact detail panel on the right showing the group
name (click to rename), stats on one line, an On/Off toggle and a delete button.
Below that is a navigation-only category list — click any category to select it
in the sidebar and show its options. The group toggle in the detail panel is
fully undoable.

Weight tiers — expanded to six
--------------------------------------------------------------------------------
Option weight tiers expanded from three to six: Ultra High (98%), High, Normal,
Low, Rare, Ultra Rare (2%). Left-click a weight badge to cycle up, right-click
to cycle down. The probability math is fixed so Ultra High and Ultra Rare have
guaranteed exact percentages regardless of what other tiers are in the same
category. All weight changes push to the undo stack.

Unified selection style
--------------------------------------------------------------------------------
Options, categories, collections and presets all share the same selection look:
a blue left accent and a blue tint row background. Groups use a left accent only
since they are card-style containers. Switching themes correctly updates the
selection highlight colour in both dark and light mode.

Disabled state fading
--------------------------------------------------------------------------------
Collections, groups, categories and options all fade to 40% opacity when their
toggle is turned off. Fading applies everywhere the item appears — sidebar,
group detail panel, collections management screen.

Inline editing
--------------------------------------------------------------------------------
Everything can be renamed by clicking the name a second time. A TextBox appears
in place, pre-filled and selected. Enter or click away commits. Escape cancels.
All renames push to the undo stack and can be reversed with Ctrl+Z.

Undo — Ctrl+Z
--------------------------------------------------------------------------------
A 10-action undo stack covers all mutations: add, rename, delete, duplicate,
reorder, toggle, weight change, cut and paste. Ctrl+Z works everywhere in Manage
Content and on the Presets screen. A toast confirms each undo with a description
of what was reversed.

Copy, cut and paste — Ctrl+C / Ctrl+X / Ctrl+V
--------------------------------------------------------------------------------
Internal clipboard supports copy and cut at option, category and group level.
Ctrl+C copies selected item(s). Ctrl+X dims the source and marks it for move.
Ctrl+V pastes at the bottom of the selected target container. Level enforcement
applies — options paste into categories, categories paste into groups. Name
collisions get a counter suffix. Escape cancels a cut and restores the source.

Delete key
--------------------------------------------------------------------------------
Delete key deletes the currently selected option, category or group. Respects
the Confirm on Delete setting. Pushes to the undo stack. Works anywhere in
Manage Content and on the Presets and Collections screens.

Duplicate — Ctrl+D
--------------------------------------------------------------------------------
Ctrl+D duplicates the selected item at any level: option, category, group,
collection or preset. Multi-select works — Ctrl+D on multiple selected groups
duplicates all of them. Duplicates get a counter suffix and are inserted
immediately after the source. All duplicates push to the undo stack.

Drag and drop — Ctrl+drag copy mode
--------------------------------------------------------------------------------
Hold Ctrl while dragging to copy instead of move. The ghost border turns green
with a COPY badge. Releasing without Ctrl performs a move as before. Drag and
drop remains available for all levels — options, categories, groups, collections
and presets. All drag operations push to the undo stack.

Result display — grouped cards
--------------------------------------------------------------------------------
Results are displayed as one card per group rather than a flat grid. Each card
shows the group name in a header with a blue left accent, and category / option
pairs in a two-column layout below. Cards expand to fill width with one or two
groups; fixed 240px with three or more. Clicking a result row dims it to 30%
opacity to mark it as ignored. Click again to undim.

Mark as Drawn
--------------------------------------------------------------------------------
A Mark as Drawn button appears in the result header after generating. Clicking it
toggles the drawn state on the current result and updates the matching history
entry. Drawn entries show a green checkmark dot in the recent history strip and
in the History screen. An All / Drawn filter in the History screen shows only
drawn entries.

AI Prompt
--------------------------------------------------------------------------------
The AI Prompt button copies a structured prompt to the system clipboard in one
click. The format is: collection name, then each group with its category/option
pairs. Dimmed rows are excluded from the prompt. A toast confirms the copy.
Available on the main screen and in the result detail dialog.

Print preview
--------------------------------------------------------------------------------
The Print button opens a print preview showing a two-column card layout styled
for paper. Group headers use a blue left accent and light tint background.
Category labels are dark, option values are bold dark blue. The Print button
sends to the Windows print dialog. Print is available on the main screen and in
the result detail dialog.

Presets — rebuilt
--------------------------------------------------------------------------------
The Presets screen is fully rebuilt with the unified selection style. Click to
select, second click to rename inline, Ctrl+D to duplicate, Delete key to delete.
No pencil or trash icons. A Load button on each row triggers a confirmation
before applying the preset state. Presets now capture and restore group enable
state in addition to category and option state. All changes push to the undo
stack. A quick-load popup on the main screen summary bar gives fast access to
presets without navigating to the Presets screen.

Collections Management
--------------------------------------------------------------------------------
The Collections Management screen gains unified selection, inline rename, Ctrl+D
duplicate, Delete key delete, and Ctrl+Z undo to match the rest of the app.

Settings — data export
--------------------------------------------------------------------------------
A new Data section in Settings has an Export button that saves the full
categories.json to a user-chosen location. The default filename is
RandomCreation_categories.json. The last export folder is remembered between
sessions. A toast confirms the export.

Settings — keyboard shortcuts
--------------------------------------------------------------------------------
The keyboard shortcuts reference table is updated for v3.0 and now lists all
13 shortcuts including Undo, Copy, Cut, Paste, Delete, Ctrl+drag copy modifier
and Duplicate.

Toast notifications
--------------------------------------------------------------------------------
Toast notifications appear below the title bar centred. Each toast fades in,
holds two seconds, then fades out. A new toast replaces an existing one
immediately. Toasts confirm: undo actions, copy/cut/paste, duplicate, preset
load, data export and AI prompt copy.

Bug fixes
--------------------------------------------------------------------------------
Drag top and bottom edge detection was missing the first and last item on some
window sizes. Fixed by clamping the insertion index at both ends.

Rare list scramble after drop is fixed by validating and clamping the drop index
at mouse-up and skipping same-position mutations.

Font size flicker when switching between Large and Extra Large is fixed by
batching the scale change through the dispatcher at Render priority.

Drag insertion index drifted at non-Normal font sizes because coordinate
calculations did not account for the active ScaleTransform. Fixed by using
TranslatePoint for all hit-testing.

Gear icon rendered as a flower emoji on some machines. Replaced with a custom
SVG path icon.

App icon was missing in the title bar at 100% DPI on integrated graphics. Fixed
by embedding the icon as a compiled resource with high-quality bitmap scaling.

Assembly version in the Settings About section was hardcoded as 2.0. Now read
from the assembly at runtime.

Tooltip delay is now 400ms, down from the slow WPF default.


================================================================================


Version 2.0 — May 2026
================================================================================

Collections
--------------------------------------------------------------------------------
Added Collections as a new top-level container for organizing categories. You
can create as many collections as you want — Creatures, Starships, Guns, etc.
Each collection can be enabled or disabled independently. Only enabled collections
appear in the sidebar when managing content, and only enabled collections are
included when generating a result. Collections can be reordered via drag and drop.
All existing categories from v1.0 are automatically migrated into a collection
called "My Collection" on first launch.

Manage Content Screen
--------------------------------------------------------------------------------
Replaced the v1.0 Edit Categories screen with a new Manage Content screen. The
left sidebar now has two zones — the top zone shows your collections, the bottom
zone shows the categories belonging to whichever collection is selected. The right
panel shows the options for whichever category is selected. A gear icon in the
collections zone opens the Collections Management screen where you can add, rename,
delete, reorder and enable/disable your collections.

Presets
--------------------------------------------------------------------------------
Added a Presets screen accessible via the bookmark icon in the Manage Content title
bar. Presets let you save and instantly restore named snapshots of your current
enabled/disabled state — down to the individual option level. Each preset row shows
a summary of how many collections, categories and options are enabled. Rows expand
to show a per-collection breakdown. Save your current state as a new preset or
overwrite an existing one from the same dialog. Loading a preset asks for
confirmation before applying. Presets can be renamed, deleted and reordered via
drag and drop. Saved to data/presets.json.

Themes
--------------------------------------------------------------------------------
Added dark theme, light theme and System Default which follows your Windows setting.
The active theme can be changed in Settings or toggled instantly using the sun/moon
icon in the main title bar. All screens, dialogs and controls respond to the active
theme including the ON/OFF pills, weight badges, hover states and scrollbars.
Settings updates the title bar icon and the title bar icon updates the Settings
button highlights — both stay in sync.

Per-option enable/disable and probability
--------------------------------------------------------------------------------
Individual options can now be toggled on or off independently of their weight tier.
A live percentage column on each option row shows the exact probability of that
option being selected during generation. The percentage updates instantly as you
change weights or toggle options on and off. Disabled options always show 0% and
are excluded from the weighted pool entirely.

Result card dimming
--------------------------------------------------------------------------------
Clicking a result card on the main screen dims it to about 35% opacity, letting
you mark individual results as ignored for your current reference or drawing session.
Clicking a dimmed card restores it. The dim state is saved per history entry so past
results show exactly what was dimmed at the time. Generating a new result clears all
dims on the current result before saving it to history.

Drag and drop — rebuilt
--------------------------------------------------------------------------------
Drag and drop has been completely rebuilt for all lists in the app. Dragging now
shows a semi-transparent wireframe ghost of the item following your cursor, and a
blue insertion line centered between items shows exactly where the item will land.
The ghost border turns red over invalid drop zones. Categories can be dragged from
one collection to another — the target collection row highlights blue. Options can
be dragged from one category to another — the target category row highlights blue.
All sub-items, weights and enable/disable states move with the dragged item.

History improvements
--------------------------------------------------------------------------------
History entries can now be deleted individually using a delete button on each row,
or all at once using the Clear All button in Settings. The history detail dialog now
shows a header with the active collection context at generation time. History limit
is configurable in Settings — default is 500 entries with oldest automatically
removed, or set to unlimited to keep everything.

Settings screen
--------------------------------------------------------------------------------
Added a dedicated Settings screen with six sections:
- Theme: Dark, Light or System Default
- Font Size: Normal, Large (1.3x) or Extra Large (1.7x) with a live preview
- History: limit toggle between 500 entries and unlimited, and Clear All
- Behavior: Confirm on delete toggle
- Window: Reset window and sidebar to default dimensions
- Keyboard shortcuts reference
- About: version info and changelog loaded from data/changelog.txt

Font scaling applies a LayoutTransform to the entire content area so all text,
rows, cards and padding scale proportionally. The window can be resized to
accommodate larger font sizes.

Resizable sidebar
--------------------------------------------------------------------------------
The sidebar divider between the categories zone and the options panel is now
draggable. The sidebar width is saved between sessions and restored on next launch.

Summary bar
--------------------------------------------------------------------------------
The main screen now shows a summary bar below the title bar listing the currently
enabled collections with a count of active categories and options. This gives a
quick overview of what will be included in the next generate before pressing the
button.

Custom borderless window
--------------------------------------------------------------------------------
The standard Windows title bar has been replaced with a custom borderless design
that matches the active theme. The title bar includes the app icon, navigation
buttons, sun/moon theme toggle, history clock, settings gear and standard window
controls. The window can be dragged from the title bar and resized from all edges
and corners as normal.

Data folder
--------------------------------------------------------------------------------
All app data is now stored in a data/ folder next to the exe, replacing the single
creature_crafter_data.json file from v1.0. The four files are:
- data/settings.json  — theme, font size, window geometry, sidebar width
- data/categories.json — all collections, categories and options
- data/history.json   — full generation history
- data/presets.json   — saved presets
- data/changelog.txt  — this file (edit freely to add your own notes)
Copying the data/ folder to another machine transfers your full setup.
